      AI Context Engineering Architecture

      This platform implements the full 7-stage Context Lifecycle to solve prompt bloating and ambiguous AI generation failures:

      • 1. Generation: Transforms high-level requirements into strongly typed Pydantic entities.
      • 2. Representation: Categorizes requirements, pages, components, APIs, and design tokens with stable IDs.
      • 3. Storage: Retains context in a decoupled in-memory store for instantaneous subgraph traversal.
      • 4. Retrieval: Precise entity extraction by ID or dependency link.
      • 5. Management: Human-in-the-loop review and editing gate.
      • 6. Optimization: Graph dependency pruning & heuristic compression to achieve ≥50% token reduction.
      • 7. Minimum-Sufficient Prompt: Synthesizes a dense, ready-to-paste AI agent prompt.
